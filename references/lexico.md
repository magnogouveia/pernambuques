# Léxico pernambucano por registro e origem

Registro: **G** = gíria (só modo girias) · **T** = tradicional (vale no formal e no girias) · **NE** = Nordeste geral (não prova Pernambuco; use com parcimônia, só girias) · **X** = fora de Pernambuco ou arcaico (nunca).
Origem: RMR = Região Metropolitana do Recife · INT = interior (agreste/sertão) · NE = vários estados · CE/BA/PA/SE = outro estado ou Sudeste.
